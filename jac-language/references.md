# References and further study

## Official Jac resources

- Jac documentation. https://docs.jaseci.org/ — Consult the documentation matching your installed release for current language grammar, installation, commands, standard libraries, walker semantics, and examples.
- Jaseci Labs GitHub organization. https://github.com/Jaseci-Labs — Source repositories, issue tracking, examples, and release material for the Jac ecosystem.
- Jac language repository. https://github.com/Jaseci-Labs/jaclang — Language implementation and development resources. Check repository documentation and release notes before relying on a particular syntax form.

## Background concepts

- Gross, Jonathan L., Jay Yellen, and Ping Zhang. *Handbook of Graph Theory*, 2nd ed. CRC Press, 2013. Reference material on graph concepts and terminology.
- Sedgewick, Robert, and Kevin Wayne. *Algorithms*, 4th ed. Addison-Wesley, 2011. Chapters on graph search, reachability, and cycle handling.

## Practical note

The code in this bundle is intentionally marked conceptual where Jac syntax may differ among releases. Verify it with the official documentation and a small local test graph. Record the Jac version in project documentation so collaborators can reproduce behavior.
